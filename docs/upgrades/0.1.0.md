# Porting note: 0.1.0

The first release. There is nothing to port: an app made from 0.1.0 starts here.

A later note in this directory (`docs/upgrades/<version>.md`) says, for apps moving to that version:

- **What changed**, in the kit's words.
- **What merges by itself.** `node scripts/upgrade.mjs --to <version>` three-way merges every file
  the kit changed.
- **What needs a hand.** This covers renamed files, changes to `launch.kit.json`, new environment
  variables, and migrations an app must generate itself.
- **How to check.** At minimum `pnpm install && pnpm gate`, plus anything specific to the release.
