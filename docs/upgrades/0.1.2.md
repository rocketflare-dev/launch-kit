# Porting note: 0.1.2

## What changed

- `scripts/lib/kit-manifest.mjs` accepts `"kind": "base64-32"` for a `launchProvides.generated`
  secret: Launch writes its 32 random bytes as standard base64 (44 characters) instead of 64 hex
  characters. `hex64` is unchanged and stays the kind of this kit's `SESSION_SECRET`.
- It also accepts `declaredConfig.plain`: an array of UPPER_SNAKE names from
  `declaredConfig.optional` that are plain vars, not secrets (Launch shows them as vars). It
  defaults to `[]`, so every optional name is a secret unless listed there.

## What merges by itself

All of it: `node scripts/upgrade.mjs --to 0.1.2` merges `scripts/lib/kit-manifest.mjs` and its
tests.

## What needs a hand

Nothing. Your `launch.kit.json` stays valid as it is. If your app reads a non-secret optional
setting (a public key or an endpoint URL), you can list it under `declaredConfig.plain` as well
as `declaredConfig.optional`.

## How to check

`pnpm install && pnpm gate`, then `node scripts/kit-check.mjs`.
