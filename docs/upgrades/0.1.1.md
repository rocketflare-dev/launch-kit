# Porting note: 0.1.1

## What changed

- `scripts/kit-check.mjs` treats an app manifest with `"app": null` as the kit itself (only its
  `kit` block is checked). A copy's app manifest must still carry `kit.id`, `kit.version` and
  `kit.commit`.
- `scripts/lib/kit-manifest.mjs` validates three optional `launch.kit.json` fields the way Launch
  does: `kit.repo` (a non-empty string), `worker.titles` (an object of BINDING → suffix, each suffix
  matching `^[a-z0-9][a-z0-9-]*$`) and `launchProvides.oidc.label` (an UPPER_SNAKE env name).
- The checker files (`scripts/kit-check.mjs`, `scripts/lib/{kit-manifest,toml-lite,yaml-lite}.mjs`)
  now say in their headers that the Rocketflare kit ships the same files.

## What merges by itself

All of it: `node scripts/upgrade.mjs --to 0.1.1` merges the four script files and their tests.

## What needs a hand

Nothing, unless your `launch.kit.json` already uses one of the three fields. If it does, make sure
`kit.repo` is non-empty, every `worker.titles` value is lowercase letters, digits and dashes, and
`launchProvides.oidc.label` is an UPPER_SNAKE env name. `node scripts/kit-check.mjs` reports any
that are not.

## How to check

`pnpm install && pnpm gate`, then `node scripts/kit-check.mjs`.
